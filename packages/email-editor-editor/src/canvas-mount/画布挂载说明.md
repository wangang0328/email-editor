# 编辑画布 DOM 挂载说明

> 模块路径：`packages/email-editor-editor/src/canvas-mount`  
> 统一挂载入口：`mountEditCanvas()`  
> 消费方：`MjmlDomRender.tsx`（编辑 Tab）

---

## 1. 背景与目标

编辑 Tab 的完整渲染管线分为两段：

```
① 编译段：pageData → JsonToMjml → mjml-browser → HTML 字符串
② 挂载段：HTML → Shadow DOM（可交互画布）
```

**编译段**由 `render-cache`（L1/L2/L3）优化，决定「HTML 从哪来」。  
**挂载段**由本模块优化，决定「HTML 如何进 Shadow DOM」。

### 改前 vs 改后

| | 改前 | 改后（本模块） |
|---|------|----------------|
| 挂载方式 | `HtmlStringToReactNodes` 整页转 React 树 + `createPortal` | `postProcessEmailHtml` + 直接 DOM |
| 典型耗时（L 档） | `htmlToReact` ~300ms | `postProcess` ~5ms + `commit` ~5–15ms |
| 段级更新 | 每次整树重建 | 未变 section **不动 DOM**（M1） |

交互能力（contenteditable 输入、选中、拖放、工具栏）**不依赖 React reconciliation**，本模块只替换挂载层。

---

## 2. 与 render-cache 的关系（重要）

两层正交，需配合才打通全链路：

| 层级 | 所属模块 | 优化段 | 做什么 |
|------|----------|--------|--------|
| **L3** | render-cache + MjmlDomRender | ① + ② | 富文本聚焦：冻结 DOM，不编译、不挂载 |
| **L1** | render-cache | ① | Undo 等：整页 HTML 命中，零编译 |
| **L2** | render-cache | ① | 只重编译变了 section 的 HTML，再拼接 |
| **M1** | canvas-mount（本模块） | ② | 段级 DOM：未变 section 不 innerHTML / 不 replace |

### 案例：改 1 个 Section 背景色

```
form 更新 section[1]
  → ① L2：S0/S2… 段 HTML 缓存命中，仅 S1 编译，拼 fullHtml
  → ② postProcessEmailHtml(fullHtml) 一次
  → ② buildMountPlan：S0/S2 action=skip，S1 action=replace
  → ② commitMountPlan：仅 S1_live.replaceWith(fragment)
```

### 3.1 模块职责

| 文件 | 职责 |
|------|------|
| `EditCanvasMount.ts` | 统一入口，编排 postProcess → plan → commit，输出埋点 |
| `postProcessEmailHtml.ts` | 解析 HTML、执行后处理、序列化 `mountHtml` |
| `annotateDocument.ts` | 注入 `data-selector`、块导航 `role=tab` |
| `contentEditableMarkers.ts` | Text/Button/Navbar/Table 的 contenteditable 标记 |
| `serializeMountHtml.ts` | 将 head + body 可渲染子节点拼接为挂载字符串 |
| `buildMountPlan.ts` | 段 `subtreeHash` / uid 集合 diff，产出 MountPlan（含 remove / splice 零编译） |
| `surgicalSegmentDom.ts` | 手术式删段 / 对齐段序（零编译） |
| `commitMountPlan.ts` | 整页 `innerHTML`、段级 morph、或零编译 remove/splice |
| `htmlToFragment.ts` | `outerHTML` → `DocumentFragment`（内存构建，不触发 layout） |
| `findElementByNodeIdx.ts` | 在 Document / live DOM 中按 `node-idx` 查找段根 |
| `types.ts` | 入参、出参、MountPlan 类型定义 |

## 4. postProcess：HTML 后处理

从 `HtmlStringToReactNodes` 抽离，**不做** `React.createElement`。

### 4.1 处理步骤

```
rawHtml（mjml-browser 输出）
  → DOMParser 解析
  → 链接 tabindex=-1（防止抢走块选中焦点）
  → 合并标签 Badge 转换（可选，enabledMergeTagsBadge）
  → annotateDocumentForEditCanvas（data-selector、contenteditable、role=tab）
  → serializeMountHtml（head + body 子节点 outerHTML 拼接）
```

### 4.2 挂载结构

与旧版 `HtmlStringToReactNodes` 一致：**不生成** `<html>` / `<head>` / `<body>` 外壳，仅将 head 与 body 下可渲染子节点并列写入容器。

典型内容：`<style>` 标签 + 邮件正文块（section / hero 等）。

### 4.3 可编辑块标记

| 块类型 | contenteditable 注入位置 | data 属性 |
|--------|--------------------------|-----------|
| Text | 块内 `<div>` | `data-content_editable-type=rich_text` |
| Button | `<a>` 或 `<p>` | `type=text` |
| Navbar | 块根或 `.mj-link` | `type=text` |
| Table | 各 `<td>` | `type=rich_text`，idx 含行列路径 |

逻辑见 `contentEditableMarkers.ts`，与 `HtmlStringToReactNodes` 完全对齐。

### 4.4 API

```ts
import { postProcessEmailHtml, postProcessDocument } from '@/canvas-mount';

// 字符串入口（挂载管线使用）
const { mountHtml, document } = postProcessEmailHtml(rawHtml, {
  enabledMergeTagsBadge: true,
});

// Document 入口（HtmlStringToReactNodes 过渡期复用）
postProcessDocument(doc, { enabledMergeTagsBadge: true });
```

## 5. M1：段级 DOM 挂载

### 5.1 渲染段（Segment）

与 L2 共用 `collectRenderSegments(pageData)`（`render-cache/segments.ts`）：

- 颗粒度：`section` / `hero` / `group`（`SEGMENT_BLOCK_TYPES`）
- 每段：`idx` + `subtreeHash`
- 含 `condition` / `iteration` 的段：`cacheable=false`，整页降级

### 5.2 MountPlan 决策

```
buildMountPlan(pageData, processedDocument, container, prevHashes)
```

| mode | 条件 | DOM 行为 |
|------|------|----------|
| **noop** | 所有段 `subtreeHash` 与上一帧相同 | 零 DOM 写入 |
| **segment** | 部分段 hash 变化，且 live DOM 可定位 | 仅 `replace` 变更段 |
| **full** | 冷启动、增删 section、切片失败、不可缓存段等 | 整页 `innerHTML` |

### 5.3 降级为 full 的条件

- 容器尚无子节点（首次挂载）
- 无 `prevSegmentHashes`
- 段 idx 集合变化（增删 / 移动导致 idx 漂移）
- 子树含 condition / iteration 等动态块
- `findElementByNodeIdxInRoot` 在 live DOM 中找不到待替换段
- 从 processed Document 切出的 `outerHTML` 为空

### 5.4 提交流程

```ts
// segment 模式（同步批量，同一 useEffect 任务内完成）
for (item of plan.segments) {
  if (item.action === 'skip') continue;
  const live = findElementByNodeIdxInRoot(container, item.idx);
  const fragment = htmlToFragment(item.outerHtml);
  live.replaceWith(fragment);
}

// full 模式
container.innerHTML = plan.mountHtml;
```

## 6. L3 与挂载跳过

富文本聚焦期间，`MjmlDomRender` 传入 `skipMount: true`：

- **编译段**：返回冻结的 `lastCompiledHtmlRef`（L3）
- **挂载段**：`mountEditCanvas` 返回 `mode: 'skipped'`，**不修改 live DOM**

失焦后 `isTextFocus=false`，effect 重新执行，走正常 L2 + M1 流程。

```
打字中  → skipped（保留 contenteditable DOM）
失焦后  → L2 编译变更段 → M1 只 replace 该段
```

## 7. 集成方式

### 7.1 MjmlDomRender 中的调用

```ts
useEffect(() => {
  if (!containerRef || !html || !pageData) return;

  const mountResult = mountEditCanvas({
    container: containerRef,
    rawHtml: html,                    // 来自 compileWithRenderCache
    pageData,
    options: { enabledMergeTagsBadge },
    prevSegmentHashes: prevSegmentHashesRef.current,
    skipMount: isTextFocus,           // L3
  });

  if (mountResult.mode !== 'skipped') {
    prevSegmentHashesRef.current = mountResult.segmentHashes;
  }
}, [containerRef, html, pageData, enabledMergeTagsBadge, isTextFocus, renderVersion]);
```

### 7.2 完整管线（编辑 Tab）

```
formState.values.content 变化
  → MjmlDomRender 本地 pageData 同步
  → ① compileWithRenderCache（L3 → L1 → L2 → miss）
  → ② mountEditCanvas（postProcess → MountPlan → commit）
  → Shadow DOM 可交互画布
```

预览 Tab **不走本模块**，仍使用 `HtmlStringToPreviewReactNodes`（只读）。

## 9. 典型场景

| 场景 | ① 编译 | ② 挂载 mode |
|------|--------|-------------|
| 冷启动 | miss（全量 mjml） | `dom-full` |
| 改 1 个 section 背景 | L2（只编译 1 段） | `dom-segment` |
| Undo 到历史快照 | L1（零编译） | `dom-noop`（hash 全同） |
| 富文本打字中 | L3（零编译） | `skipped` |
| 末尾新增 section | L2 或 miss | `dom-full`（idx 集合变化） |
| 删除中间 section | miss | `dom-full`（idx 漂移） |
| 含 condition 段模板 | 可能 miss | `dom-full` |

---

## 10. 不是什么

| 误解 | 实际 |
|------|------|
| 去掉 React 挂载 = 去掉 mjml | ❌ 编译仍走 `compileWithRenderCache` + mjml |
| 本模块替代 render-cache | ❌ 两层正交，各司其职 |
| postProcess 可以省略 | ❌ `node-idx`、`contenteditable` 仍必须注入 |
| 预览 Tab 也走 canvas-mount | ❌ 仅编辑 Tab |
| M1 = L2 | ❌ L2 优化 HTML 来源，M1 优化 HTML 入 DOM 方式 |
